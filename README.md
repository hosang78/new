# 슬기로운 신입생활 : AI 상황극 (휴대폰용)

신입직원이 휴대폰으로 접속해 메뉴를 고르고, AI 상황극의 세 가지 상황(까다로운 고객 · 업무를 지시하는 상사 · 협업이 어려운 동료)에 답변을 제출하는 페이지입니다.
답변은 **구글 시트**에 쌓이고, 시트의 `AI반응` · `AI대사` 칸이 채워지면 휴대폰 화면의 캐릭터가 긍정/부정 반응 GIF로 바뀝니다.
PC(진행자) 화면은 나중에 만들며, 그 화면이 이 두 칸을 채우게 됩니다.

```
index.html          메인 메뉴 (카드형: PC 한 줄 3개, 휴대폰 1개씩), 오른쪽 위 관리자 아이콘
roleplay.html       AI 상황극 (상황 선택 → 답변 → AI 반응)
admin.html          관리자 화면 (답변 잠금 켜기/끄기, 제출 현황)
js/config.js        ★ 시트 주소(API_URL)와 메뉴 목록 설정
js/scenarios.js     기본 상황 문구 (시트 연결 전/오류 시 사용)
apps-script/Code.gs 구글 시트에 붙여 넣을 Apps Script
assets/mobile/      휴대폰용 배경·캐릭터 GIF
```

---

## 1단계. 구글 시트 만들기

1. 새 구글 시트를 만듭니다. 이름은 예를 들어 `슬기로운 신입생활 응답`으로 정합니다.
2. 메뉴 **확장 프로그램 → Apps Script**를 엽니다.
3. 기본 코드를 지우고 `apps-script/Code.gs` 내용을 모두 붙여 넣은 뒤 저장(💾)합니다.
4. 위쪽 함수 선택 칸에서 **`setup`**을 고르고 **실행**합니다.
   - 처음 실행하면 권한을 요청합니다. **권한 검토 → 계정 선택 → 고급 → (프로젝트) 이동 → 허용**을 차례로 누릅니다.
   - 시트에 `상황`, `답변`, `설정` 탭이 생깁니다.
5. **`설정` 탭의 `관리자 비밀번호` 값 칸(B2)에 비밀번호를 직접 적습니다.** 비워 두면 관리자 로그인이 되지 않습니다.

## 2단계. 웹 앱으로 배포하기

1. Apps Script 오른쪽 위에서 **배포 → 새 배포**를 누릅니다.
2. 톱니바퀴(유형 선택)에서 **웹 앱**을 고릅니다.
   - 실행 사용자: **나**
   - 액세스 권한: **모든 사용자** (신입직원이 로그인하지 않아도 제출할 수 있게)
3. **배포**를 누르고 나오는 **웹 앱 URL**(`https://script.google.com/macros/s/…/exec`)을 복사합니다.
4. 이 URL을 브라우저에 열어 `{"ok":true,"message":"슬기로운 신입생활 API 작동 중"}`이 보이면 정상입니다.

> Code.gs를 고친 뒤에는 **배포 → 배포 관리 → ✏️ 수정 → 버전: 새 버전 → 배포**를 해야 반영됩니다. 이렇게 하면 URL은 바뀌지 않습니다.

## 3단계. 페이지에 시트 주소 넣기

`js/config.js`의 `API_URL`에 2단계에서 복사한 URL을 넣습니다.

```js
API_URL: 'https://script.google.com/macros/s/XXXXXXXX/exec',
```

URL을 비워 두면 **데모 모드**로 동작합니다. 이때 답변은 그 휴대폰에만 저장되고, 화면 오른쪽 위에 `데모 모드`가 표시됩니다.

## 4단계. GitHub Pages로 공개하기

1. GitHub 저장소 **Settings → Pages**로 갑니다.
2. Source: **Deploy from a branch**, Branch: 배포할 브랜치 / `/ (root)`를 고르고 저장합니다.
3. 1~2분 뒤 `https://<계정>.github.io/<저장소>/` 주소가 생깁니다. 이 주소를 QR코드로 만들어 신입직원에게 보여 주면 됩니다.

> 무료 계정에서 **비공개 저장소**는 GitHub Pages를 쓸 수 없습니다. 이 경우 저장소를 공개로 바꾸거나 Netlify처럼 폴더를 끌어다 놓는 정적 호스팅을 쓰면 됩니다. 사내 보안 정책도 함께 확인하세요.

## 운영 방법

### 상황 문구 바꾸기
시트의 `상황` 탭에서 바로 고치면 됩니다. 다음에 페이지를 열 때 반영됩니다.

| 칸 | 설명 |
|---|---|
| id | `customer` / `manager` / `colleague` 중 하나 (이미지와 연결되므로 바꾸지 마세요) |
| 순서 | 목록에 보이는 순서 |
| 한줄 대사 | 목록 카드에 보이는 짧은 대사 |
| 상대 대사 | 플레이 화면 말풍선 |
| 평가 포인트 | **휴대폰에는 보내지 않는** AI 채점 기준. 나중에 PC에서 AI에게 넘길 기준입니다 |
| 사용 | `N`으로 바꾸면 휴대폰 목록에서 숨겨집니다 |

### 답변 확인 · AI 반응 넣기
`답변` 탭에 제출이 한 줄씩 쌓입니다.

| 제출ID | 제출시각 | 참여자(익명) | 상황ID | 상황 | 답변 | **AI반응** | **AI대사** | 반응시각 |
|---|---|---|---|---|---|---|---|---|

- `AI반응`을 **긍정** 또는 **부정**으로 고르고 `AI대사`에 상대역의 대사를 적으면, 5초 안에 그 신입직원 휴대폰의 캐릭터가 해당 반응 GIF와 대사로 바뀝니다.
- PC 화면을 만들기 전이라도 진행자가 시트에서 직접 입력해 리허설할 수 있습니다.
- 참여자는 `R-7F3K2Q` 같은 익명 코드로만 기록됩니다. 휴대폰마다 고정이라 같은 사람의 답을 묶어 볼 수 있습니다.

### 관리자 화면 (답변 잠금 · 제출 현황)
메인 화면 오른쪽 위의 방패 아이콘을 누르고 `설정` 탭의 관리자 비밀번호를 입력합니다.

- **답변 마감하기**: 신입직원은 새 답변 제출과 '다시 답하기'를 할 수 없습니다. 상황 화면과 이미 낸 답, AI 반응은 계속 볼 수 있습니다. 작성 중에 마감되면 쓰던 글은 남고 제출 버튼만 막힙니다.
- **답변 다시 받기**: 잠금을 풉니다.
- **제출 현황**: 전체 답변 수, 참여자 수, AI 반응 대기 수, 상황별 긍정·부정·대기 수가 10초마다 자동으로 새로 고쳐집니다.
- 잠금은 서버(Apps Script)에서 확인하므로, 페이지를 조작해도 마감 뒤에는 시트에 저장되지 않습니다.
- 시트 `설정` 탭의 `답변 잠금`을 직접 `Y`/`N`으로 바꿔도 됩니다.
- 한 번 로그인하면 그 기기에서는 30일 동안 다시 묻지 않습니다. 비밀번호를 바꾸면 모든 기기의 로그인이 풀립니다. 비밀번호를 5번 틀리면 5분 동안 로그인할 수 없습니다.
- 이미 배포한 뒤 Code.gs를 바꿨다면 **배포 → 배포 관리 → ✏️ 수정 → 새 버전**으로 다시 배포해야 반영됩니다.

## 나중에 PC 화면을 만들 때 연결 지점
- 새 답변을 가져올 때: `답변` 탭에서 `AI반응`이 비어 있는 행을 읽습니다.
- AI가 판단할 때: `상황` 탭의 `상대 대사`, `질문`, `평가 포인트`와 신입직원의 `답변`을 AI에 넘기고 `{reaction: "positive" | "negative", line: "…"}` 형태로 결과를 받습니다.
- 결과를 쓸 때: `AI반응`(긍정/부정), `AI대사`, `반응시각`을 기록하면 휴대폰에 자동으로 표시됩니다.
- PC용 이미지(1920×1080 배경, 560×672 GIF)는 원본 압축 파일의 `assets/pc/`에 있습니다.

## 참고 · 주의
- 웹 앱 URL을 아는 사람은 누구나 답변을 제출할 수 있습니다. 교육 당일에만 링크를 공유하고, 끝나면 배포를 보관(중지)하는 것을 권장합니다.
- 답변 입력은 500자로 제한되고, `=`나 `+`로 시작하는 입력은 시트 수식으로 실행되지 않도록 처리됩니다.
