## 0. 한눈에 보기
신입직원 AI 시연 교육에서, 신입직원들이 휴대폰에 손가락으로 **"수협의 미래"** 그림을 그려 제출했습니다. 그림은 구글 드라이브에 저장돼 있습니다. 아래 두 가지를 부탁합니다.

| 작업 | 내용 |
|---|---|
| **A. AI 이미지 완성** | 드라이브의 원본 그림과 작품 설명을 읽고, **선·형태·구도를 최대한 살린 고품질 이미지**로 완성해 같은 폴더에 저장 |
| **B. 관리자(진행자) 프로그램** | 작품 목록과 상태를 관리하고, **그린 순서 재생(타임랩스) + 원본 ↔ AI 완성본**을 나란히 보여 주는 **16:9 슬라이드쇼** |

| 열 | 머리글 | 값 | 누가 씀 |
|---|---|---|---|
| O | AI이미지 | AI 완성본 파일 링크 | A 작업 |

> 시트에 적힌 정보보다 **폴더 안의 실제 파일을 우선**으로 판단하세요. 예를 들어 `SF-0001_ai.png`가 폴더에 있으면 AI 완성본이 있는 것으로 봅니다. 사람이 파일을 직접 올리는 경우도 있기 때문입니다.

### 2-3. `SF-0001_strokes.json` 형식 (실제 데이터에서 발췌)

```json
{
  "schema": "suhyup-future-drawing/v1",
  "id": "SF-0001",
  "canvas": { "width": 1200, "height": 1600, "background": "#ffffff", "origin": "top-left", "unit": "px" },
  "strokes": [
    { "n": 0, "tool": "pen", "color": "#1d2b45", "width": 12,
      "points": [[289.8, 549.8, 2701], [292.3, 549.8, 2764], [297.3, 549.8, 2764]] }
  ],
  "removedStrokes": [],
  "timeline": [ { "type": "stroke", "t": 2701, "n": 0 }, { "type": "stroke", "t": 8157, "n": 1 } ],
  "stats": { "strokeCount": 18, "totalStrokes": 18, "pointCount": 769, "undoCount": 0, "clearCount": 0,
             "drawSeconds": 9.1, "sessionSeconds": 25.3, "colorsUsed": ["#1d2b45", "#43a047", "#f08a4b", "#e04a3f"] }
}
```

**최상위 항목**

| 항목 | 내용 |
|---|---|
| `strokes` | 최종 그림에 남아 있는 선들. 그린 순서대로 들어 있습니다. |
| `removedStrokes` | 되돌리기나 전체 지우기로 최종 그림에서 빠진 선들. 형식은 `strokes`와 같습니다. |
| `timeline` | 그리는 동안 일어난 모든 동작을 시간 순서대로 적은 기록. 처음부터 끝까지 적용하면 최종 그림과 똑같아집니다. |

**선 하나의 항목** (`strokes`, `removedStrokes` 공통)

| 항목 | 내용 |
|---|---|
| `n` | 선 번호 |
| `tool` | `pen` 또는 `eraser`. 지우개는 흰색(`#ffffff`)으로 덧칠하는 선입니다. |
| `color` | 선 색 (`#RRGGBB`) |
| `width` | 1200×1600 기준 선 굵기(px). 펜은 6·12·24·44, 지우개는 그 1.6배입니다. |
| `points` | `[x, y, t]` 목록. x, y는 캔버스 좌표(px), t는 그리기를 시작한 뒤 지난 시간(ms)입니다. 연속한 점의 t가 같을 수 있습니다. |

**timeline 동작 종류**

| 동작 | 뜻 |
|---|---|
| `{ "type": "stroke", "t", "n" }` | 선 n을 그림. n은 `strokes` 또는 `removedStrokes`의 선 번호 |
| `{ "type": "undo", "t" }` | 바로 앞 동작(선 또는 전체 지우기) 취소 |
| `{ "type": "redo", "t" }` | 취소했던 동작 되살리기 |
| `{ "type": "clear", "t" }` | 전체 지우기. 이것도 되돌리기로 취소할 수 있습니다. |

## A. AI 이미지 완성

### A-1. 대상
- 시트에서 `상태 = 완료`이면서, 폴더에 `작품번호_ai.png`가 아직 없는 작품(또는 `AI상태 = 다시`인 작품)이 대상입니다.
- 한 번에 여러 작품을 처리할 때는 **작품번호 순서**로 진행해 주세요.

### A-2. 작품마다 읽을 것
1. `SF-0001_drawing.png`: 구도의 기준이 되는 원본입니다.
2. `SF-0001_info.md`: 제목과 설명. 무엇을 그리려 했는지 알려 줍니다.
3. 필요하면 `SF-0001_strokes.json`: 어떤 색을 썼는지, 무엇을 먼저 그렸는지 참고합니다. 보통 먼저 그린 것이 중심 대상입니다.

### A-3. 완성 원칙
- **구도 유지 (가장 중요)**
  - 원본에 있는 대상의 **위치, 크기, 방향, 개수**를 그대로 유지합니다.
  - 원본에 없는 큰 대상은 추가하지 않습니다.
  - 배경을 채우는 것(하늘, 바다, 빛 등)은 괜찮습니다.
- **해석**
  - 아이 그림처럼 단순한 선이라도, 제목과 설명이 말하는 대상으로 해석해 완성합니다.
  - 예: 원 + 꼬리 + "대왕 물고기" → 큰 물고기
  - 해석이 애매하면 설명 문장을 우선합니다.
- **분위기**: 밝고 희망찬 미래 수산·어촌·바다의 모습입니다. 수협 파랑(#1f6fb2)과 바다색 계열을 기본으로 하되, 원본에 쓴 색은 살립니다.
- **스타일**:
  - **모든 작품을 같은 스타일로** 그려 주세요. 슬라이드쇼에서 연속으로 보이기 때문입니다.
  - 기본값은 "따뜻한 색감의 고품질 디지털 일러스트(반실사)"입니다.
  - 첫 작품을 만든 뒤 스타일을 확정하고, 그 스타일 설명을 모든 프롬프트에 똑같이 넣어 주세요.
- **비율**: 세로 3:4를 권장합니다(예: 1536×2048). 도구 제약으로 2:3(1024×1536)만 된다면 그대로 두세요. 관리자 화면에서 비율을 맞춥니다.
- **넣지 말 것**
  - 글자와 숫자. 제목은 슬라이드에서 따로 띄웁니다.
  - 실존 기관 로고. **수협 로고를 지어내서 그리지 마세요.**
  - 실존 인물을 닮은 얼굴, 폭력적이거나 불쾌한 요소
- **부적절한 작품**: 장난이나 부적절한 내용이면 완성하지 말고 `AI상태 = 다시`, `메모`에 사유를 적어 진행자 판단에 맡겨 주세요.

### A-4. 저장 (같은 작품 폴더)

## B. 관리자(진행자) 프로그램

### B-1. 구성 (권장)
- **방식**:
  - **새 Google Apps Script 프로젝트**로 만들고, HTML 화면(HtmlService)을 웹 앱으로 배포합니다.
  - 배포 설정은 실행 사용자 **"나"**, 액세스 **"나만"**(관리자 전용)입니다.
  - 기존 그림 저장 웹 앱은 '모든 사용자' 공개이므로, **그 프로젝트에 관리자 기능을 넣지 마세요.**
- **이 방식을 권하는 이유**:
  - 드라이브와 시트를 소유자 권한으로 바로 읽을 수 있습니다(`DriveApp`, `SpreadsheetApp`).
  - 그림 파일을 공개로 바꿀 필요가 없습니다.
- **데이터 전달**:
  - 화면 ↔ 서버는 `google.script.run`으로 주고받습니다.
  - 이미지는 서버에서 base64 data URL로 넘기거나, 크기를 줄인 썸네일을 씁니다.
  - 목록에는 썸네일만 쓰고, 원본은 상세 화면이나 슬라이드에서만 불러옵니다.
- **빔프로젝터 기준**: 1920×1080 전체화면에서 보기 좋아야 하고, 1366×768 노트북에서도 깨지지 않아야 합니다.

### B-2. 화면과 기능
1. **작품 목록**
   - 시트의 `완료` 작품을 카드 그리드로 보여 줍니다. 카드 내용은 원본 썸네일, AI 완성본 썸네일(있으면), 작품번호, 제목입니다.
   - 상태 필터를 둡니다: 전체 / AI 대기 / AI 완료 / 다시 / 숨김(슬라이드 N).
   - 새로고침 버튼으로 시트와 폴더를 다시 읽습니다.
2. **작품 상세**
   - 큰 원본, 큰 AI 완성본, 제목·설명, 통계(그린 시간, 획수, 사용 색)를 보여 줍니다.
   - **타임랩스 재생**: 재생, 일시정지, 처음부터, 속도(실제 속도 / 4배 / 10배 / "N초 안에 맞춤")를 둡니다.
   - 슬라이드 포함 켜기·끄기(R열), 메모(S열), AI상태를 `다시`로 바꾸기(P열)를 둡니다. 시트에 바로 저장합니다.
3. **슬라이드쇼** (이 프로그램의 핵심)
   - **16:9 전체화면**에서 **왼쪽에 원본**, **오른쪽에 AI 완성본**을 나란히 보여 줍니다. 둘 다 세로 3:4 그림이니 같은 높이로 맞춥니다.
   - 한 작품의 연출 순서:
     1. 작품번호와 제목 자막이 나옵니다.
     2. 왼쪽에서 **타임랩스로 그려집니다**. 기본 8초 안에 맞춤.
     3. 오른쪽 AI 완성본이 **공개되는 연출**이 나옵니다(예: 붓이 지나가며 드러남).
     4. 아래에 설명 자막이 나옵니다.
     5. 잠시 머문 뒤 다음 작품으로 넘어갑니다.
   - 대상: `슬라이드 = Y`이면서 AI 완성본이 있는 작품입니다. AI 완성본이 없으면 원본 타임랩스만 보여 줍니다.
   - 순서는 작품번호순 또는 무작위입니다. 자동 넘김 간격도 설정할 수 있게 해 주세요.
   - 키보드: → 다음, ← 이전, Space 일시정지, F 전체화면, Esc 종료
   - 화면에는 **기기ID와 제출ID를 절대 표시하지 않습니다.**

### B-3. 타임랩스 재생 규칙 (원본과 똑같이 보이도록)
- 1200×1600 흰 캔버스에 `timeline`을 처음부터 적용합니다.
  - 현재 그림은 동작 스택 `ops`(선 또는 전체 지우기)로 관리합니다.
  - `stroke` → `ops`에 추가하고 `redo` 스택을 비웁니다.
  - `undo` → `ops`의 마지막 동작을 꺼내 `redo` 스택에 넣습니다.
  - `redo` → `redo` 스택에서 꺼내 다시 `ops`에 넣습니다.
  - `clear` → `ops`에 추가합니다. 화면에는 마지막 `clear` 이후의 선만 그립니다.
- 선은 `points`의 `t` 순서대로 점을 늘려 가며 그립니다.
- 재생 시간 조정:
  - 1초 넘게 쉰 구간은 0.3초로 줄입니다.
  - "N초 안에 맞춤"은 줄인 뒤의 전체 시간을 N초로 비례 조정합니다.
- 선 그리는 방식은 아래 코드를 그대로 쓰세요. 휴대폰 그림판과 똑같은 모양이 나옵니다.

```js
// c: CanvasRenderingContext2D, s: 선 하나, scale: 화면 픽셀 / 1200
function paintStroke(c, s, scale) {
  const p = s.points; if (!p.length) return;
  c.save(); c.scale(scale, scale);
  c.strokeStyle = c.fillStyle = s.tool === "eraser" ? "#ffffff" : s.color;
  c.lineWidth = s.width; c.lineCap = "round"; c.lineJoin = "round";
  if (p.length === 1) { c.beginPath(); c.arc(p[0][0], p[0][1], s.width / 2, 0, Math.PI * 2); c.fill(); c.restore(); return; }
  c.beginPath(); c.moveTo(p[0][0], p[0][1]);
  for (let i = 1; i < p.length - 1; i++) {
    const mx = (p[i][0] + p[i + 1][0]) / 2, my = (p[i][1] + p[i + 1][1]) / 2;
    c.quadraticCurveTo(p[i][0], p[i][1], mx, my);
  }
  const L = p[p.length - 1]; c.lineTo(L[0], L[1]); c.stroke();
  c.restore();
}
```
